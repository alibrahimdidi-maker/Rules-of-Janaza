GitHub Pages slide site. Module-code gate: **SHA0302**.

## Files
- `index.html` — gate + all 15 weeks (15 slides each, diagrams + mind maps)
- `fonts/Faruma.ttf` — Dhivehi font

## Show / hide weeks
At the bottom of `index.html` change:

    var LAST_VISIBLE_WEEK = 15;

(e.g. `5` shows weeks 1-5 only).
